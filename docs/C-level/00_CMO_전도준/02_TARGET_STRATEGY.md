# 02_TARGET_STRATEGY.md

> 시장조사와 프로젝트 자료를 기반으로 KOTA의 핵심 타깃 고객을 정의하고 우선 공략 시장과 전략 방향을 결정하기 위한 문서입니다.

---

# 1. 문서 목적

본 문서는 KOTA 프로젝트가 누구를 위한 서비스인지 명확하게 정의하는 문서이다.

시장조사 결과를 바탕으로 우선 공략할 사용자와 시장을 선정하며,
모든 콘텐츠 전략, UX, 기능 우선순위, SEO/GEO 전략의 기준이 된다.

본 문서는 타깃을 "추측"으로 정의하지 않으며,
반드시 프로젝트 자료와 시장조사(Evidence)를 기반으로 작성한다.

---

# 2. Target Strategy 목표

본 문서는 다음 질문에 답하는 것을 목표로 한다.

- 누구를 위한 서비스인가?
- 어떤 시장을 먼저 공략할 것인가?
- 왜 이 시장을 선택했는가?
- 가장 큰 문제를 가진 사용자는 누구인가?
- 공모전과 서비스 방향에 가장 적합한 고객은 누구인가?

---

# 3. Target 선정 원칙

Target은 다음 기준을 모두 만족해야 한다.

- 프로젝트 목적과 일치할 것
- 시장조사에서 근거가 확인될 것
- 한국관광공사 정책 방향과 부합할 것
- TourAPI 활용 가치가 높을 것
- 실제 서비스 확장 가능성이 있을 것

근거 없는 타깃은 선정하지 않는다.

---

# 4. Primary Target

## 핵심 타깃

※ 압축파일 및 시장조사 내용을 기준으로 작성

예시 작성 항목

- 국가
- 연령
- 여행 형태
- 방문 목적
- 여행 빈도
- 디지털 활용 수준

---

## 핵심 Pain Point

시장조사에서 확인된 문제를 작성한다.

예시

- 관광 정보가 분산되어 있다.
- 지역 축제를 찾기 어렵다.
- 여행 일정을 계획하기 어렵다.
- 추천 서비스의 신뢰도가 낮다.

※ 실제 조사 결과를 기준으로 작성

---

## Needs

핵심 타깃이 원하는 것을 작성한다.

예시

- 쉽고 빠른 관광 정보
- AI 기반 추천
- 일정 추천
- 지역 축제 추천
- 실제 방문 가치가 높은 장소

---

## JTBD (Jobs To Be Done)

사용자가 KOTA를 사용하는 목적을 작성한다.

예시

"여행 계획을 간편하게 세우고 싶다."

"현재 위치 주변에서 가볼 만한 곳을 찾고 싶다."

"다양한 즐길거리를 쉽게 찾고싶다."

"이왕 여행 온 김에 다양한 체험을 해보고 싶다."

"한국 여행을 더욱 재미있게 즐기고 싶다."

# 이 문서를 작성하면서 발견한 개선점

현재 KOTA 프로젝트는 공모전과 실제 서비스를 동시에 고려하고 있다.

따라서 Target을 단순히 "사용자" 기준으로 정의하는 것이 아니라,

- 공모전 심사위원이 인정하는 타깃인가?
- 실제 시장성이 있는 타깃인가?
- TourAPI 활용 가치가 높은 타깃인가?

를 함께 검증해야 한다.

향후 실제 사용자 인터뷰나 설문조사가 진행되면 본 문서는 가장 먼저 업데이트해야 하는 핵심 전략 문서이다.

# 06_SEO_GEO_STRATEGY.md

> KOTA 콘텐츠가 검색엔진과 AI 검색 환경에서 효과적으로 발견되고 지속적으로 유입될 수 있도록 SEO 및 GEO 전략을 정의하는 문서입니다.

---

# 1. 문서 목적

본 문서는 KOTA 콘텐츠의 검색 경쟁력을 확보하기 위한 전략 문서이다.

SEO(Search Engine Optimization)와
GEO(Generative Engine Optimization)를 함께 고려하여

- Google 검색
- AI Search
- ChatGPT
- Gemini
- Perplexity
- AI Overview

등 다양한 검색 환경에서 KOTA 콘텐츠가 자연스럽게 발견될 수 있도록 전략을 정의한다.

---

# 2. 전략 목표

본 문서는 다음 목표를 가진다.

- 관광 콘텐츠 검색 노출 확대
- AI 검색 인용 가능성 향상
- 지역 관광 키워드 선점
- TourAPI 기반 콘텐츠의 검색 가치 향상
- 장기적인 Organic Traffic 확보

# 3. SEO 전략

## 기본 원칙

모든 콘텐츠는 검색보다 사용자 경험을 우선한다.

검색을 위해 작성하는 콘텐츠가 아니라

사용자가 원하는 콘텐츠가 검색되도록 설계한다.

---

## SEO 원칙

- 검색 의도를 우선한다.
- 지역 기반 키워드를 활용한다.
- 콘텐츠 품질을 최우선으로 한다.
- 중복 콘텐츠를 최소화한다.
- 최신 정보를 유지한다.

---

# 4. GEO 전략

## 기본 원칙

AI가 이해하기 쉬운 콘텐츠를 작성한다.

단순 키워드 중심이 아닌

맥락(Context)

Entity

구조화된 정보

를 중심으로 콘텐츠를 구성한다.

---

## GEO 원칙

- 명확한 제목
- 질문 기반 콘텐츠
- 구조화된 정보
- 신뢰 가능한 출처
- 최신 데이터
- Entity 중심 작성

# 14. CMO 전략 시사점

SEO는 마케팅 기술이 아니다.

좋은 콘텐츠가 검색되는 것이 SEO이며,

GEO는 AI가 이해하기 쉬운 콘텐츠를 만드는 것이다.

따라서 SEO와 GEO는 별개의 전략이 아니라

Content Strategy를 확장하는 전략으로 운영한다.

# 이 문서를 작성하면서 발견한 개선점

KOTA의 SEO/GEO 전략은 일반적인 검색 최적화와 다르다.

검색 노출 자체가 목적이 아니라,
사용자가 필요한 순간에 KOTA 콘텐츠를 발견하고 실제 여행 결정으로 이어지도록 만드는 것이 목표이다.

또한 향후 AI 검색 환경이 확대될 것을 고려하여 모든 콘텐츠는 검색엔진뿐 아니라 생성형 AI도 이해할 수 있는 구조와 품질을 유지해야 한다.

SEO와 GEO는 독립적인 전략이 아니라 Content Strategy를 검색 환경으로 확장하는 실행 전략으로 관리한다.

# 07_CHANNEL_STRATEGY.md

> KOTA 콘텐츠를 가장 효과적으로 전달하기 위한 채널별 역할과 운영 전략을 정의하여 사용자 유입부터 여행 결정까지의 콘텐츠 흐름을 설계하는 문서입니다.

---

# 1. 문서 목적

본 문서는 KOTA의 콘텐츠를 어떤 채널에서,
어떤 목적과 역할로 운영할 것인지 정의하는 전략 문서이다.

채널의 목적은 단순 노출이나 조회수가 아니라

사용자가

KOTA를 발견하고

↓

관심을 가지며

↓

콘텐츠를 탐색하고

↓

실제 여행을 결정하도록 만드는 것이다.

# 이 문서를 작성하면서 발견한 개선점

일반적인 마케팅에서는 채널별 성과를 개별적으로 관리하는 경우가 많다.

하지만 KOTA에서는 채널이 각각 독립적으로 존재하는 것이 아니라 하나의 사용자 여정을 구성하는 연결 요소이다.

따라서 모든 채널은 '조회수'나 '팔로워 수'보다 사용자가 KOTA 서비스를 발견하고 여행을 결정하는 과정에 얼마나 기여했는지를 기준으로 평가해야 한다.

또한 콘텐츠는 채널마다 새롭게 만드는 것이 아니라, 하나의 핵심 콘텐츠를 채널 특성에 맞게 재구성(Content Repurposing)하여 운영하는 것을 기본 원칙으로 한다.

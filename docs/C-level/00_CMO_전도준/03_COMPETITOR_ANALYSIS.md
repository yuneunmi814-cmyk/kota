# 6. 시장 공백(Market Gap)

경쟁사 분석을 통해 확인된 시장의 빈 공간을 정리한다.

경쟁사 분석 결과 KOTA가 집중해야 하는 영역

- 관광 정보는 많지만 여행 결정을 돕는 UX는 부족하다.
- 지역 축제 중심 플랫폼이 부족하다.
- 이동·관광·축제를 하나의 흐름으로 연결하는 서비스가 부족하다.
- 경험(Experience)을 중심으로 콘텐츠를 제공하는 서비스가 부족하다.
- 상황(Context) 기반 AI 추천 서비스가 부족하다.
- 지역 축제 큐레이션이 부족하다.
- 콘텐츠 중심 탐색 경험이 부족하다.
- 개인화 추천이 부족하다.
- 실제 여행 결정까지 연결되는 서비스가 부족하다.

※ 반드시 조사자료를 기반으로 작성한다.

# 이 문서를 작성하면서 발견한 개선점

일반적인 경쟁사 분석은 기능 비교에 집중하는 경우가 많다.

하지만 KOTA는 공모전 프로젝트이면서 콘텐츠 중심 관광 플랫폼을 목표로 한다.

따라서 기능 수보다 **'사용자가 왜 기존 서비스에서 여행을 결정하지 못하는가'**를 분석하는 것이 더 중요하다.

본 문서는 기능 비교표가 아니라 **시장 공백(Market Gap)을 발견하기 위한 전략 문서**로 유지한다.

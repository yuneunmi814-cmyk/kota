# 버그 리포트 가이드 (COO 실무)

> 작성 2026-08-03 · 최용우(COO) · 팀 협업규칙: *윤은미 개발/배포 → 최용우 버그 리포트(모아서) → 전도준 검수*

## 대원칙

> **개발자가 재현할 수 있어야 한다. 재현 안 되는 버그는 안 고쳐진다.**

"이상해요"는 리포트가 아니라 민원이다. 리포트는 **은미가 내 화면을 안 보고도 똑같이 재현**할 수 있어야 완성.

---

## 필수 5줄 양식

```
제목  [영역] 무엇이 어떻게 잘못됐는지 한 줄

1. 재현 절차   1) ... 2) ... 3) ...
2. 기대 결과   이렇게 동작해야 함
3. 실제 결과   이렇게 동작함
4. 환경        기기 / OS / 브라우저 / URL / 발생 시각
5. 증거        스크린샷 · 화면녹화 · 콘솔 에러
```

### 심각도

| 등급 | 기준 | 대응 |
|---|---|---|
| **P0** | 서비스/데모 자체가 불가 (배포 다운, 로그인 전면 실패) | **즉시** 디스코드 멘션 |
| **P1** | 핵심 기능 깨짐 (검색·축제·식당 목록 안 뜸) | 당일 리포트 |
| **P2** | 불편하지만 우회 가능 | 모아서 |
| **P3** | 오타·정렬·디자인 사소 | 모아서 |

> 팀 규칙이 "한 번에 모아서"지만 **P0는 예외로 즉시**. 배포가 죽어있는데 이틀 모으면 안 됨.

## 나쁜 예 vs 좋은 예

### ❌ 나쁜 예
> 식당 검색이 이상해요. 안 나올 때가 있어요.

문제: 어느 지역인지, 무슨 검색어인지, 언제인지, 항상인지 가끔인지 전부 없음.
→ 은미가 "어떤 상황이요?"라고 되묻는 순간 **왕복 1일 손해**.

### ✅ 좋은 예
> **[식당] 공주 지역 선택 후 카테고리 전환 시 결과 0건**
>
> 1. **재현** 1) 식당 탭 진입 → 2) 지역 드롭다운에서 "공주" 선택(목록 정상 표시됨) → 3) 카테고리 칩 "한식" 클릭
> 2. **기대** 공주 지역 한식 목록 표시
> 3. **실제** "결과 없음" 빈 화면. 지역을 다시 선택하면 정상 복구됨 (재현율 5/5)
> 4. **환경** 갤럭시 S23 / Android 14 / Chrome 126 / `https://...` / 2026-08-03 14:20
> 5. **증거** 스크린샷 첨부. 콘솔: `TypeError: Cannot read properties of undefined (reading 'items')`
>
> 심각도 **P1** · 참고: 고양 지역에서는 재현 안 됨 → 지역별 데이터 이슈 의심

좋은 이유:
- **재현율**을 적었다 (5/5 = 항상. 가끔이면 "2/10"처럼)
- **복구 방법**을 적었다 (은미가 원인 좁히는 데 결정적)
- **재현 안 되는 조건**도 적었다 (고양은 정상 → 데이터 문제로 범위 축소)
- **콘솔 에러** 원문을 그대로 붙였다 (해석하지 말고 원문. 내 해석은 틀릴 수 있음)

## COO가 지킬 것

1. **원인 추측해서 쓰지 마라** — "아마 API가 문제인 듯" 같은 말은 은미를 잘못된 방향으로 끌고 감. **관측된 사실만.** 단, "고양은 정상"처럼 **범위를 좁히는 관측**은 최고의 정보다
2. **중복 검색 먼저** — 올리기 전에 기존 이슈 검색
3. **하나의 이슈에 하나의 버그** — 3개 묶어 올리면 하나 고치고 닫혀버림
4. **고쳤다고 하면 내가 직접 재확인 후 닫기** — 리포터가 닫는 게 원칙
5. **못 고칠 버그는 "안 고침"으로 명시하고 닫기** — 열려만 있는 이슈는 노이즈

## 콘솔 에러 보는 법 (모바일/PC)

- **PC 크롬** — `F12` → Console 탭 → 빨간 줄 전체 복사
- **네트워크 실패 확인** — `F12` → Network 탭 → 빨간 항목 클릭 → Status(4xx/5xx)와 Response 복사
- **모바일** — PC 크롬에서 `F12` → 기기 툴바(`Ctrl+Shift+M`)로 모바일 폭 재현이 가장 빠름. 실기기 전용 버그면 화면 녹화로 대체

## 정기 QA 루틴 (배포될 때마다)

**심사 데모 경로부터** 완주한다. 이 경로는 버그 0이 목표.

- [ ] 첫 진입 → 로딩 정상? 깨진 이미지 없나?
- [ ] 축제 탭 — 목록 / 상세 / 지도
- [ ] 식당 탭 — 지역 선택 · 카테고리 · 검색 · 상세
- [ ] 교통 — 경로/거리 표시
- [ ] 로그인 — 카카오 / 구글 / 라인 각각
- [ ] 모바일 실기기 (안드로이드 + iOS 사파리)
- [ ] 외국어 경로 (태국어·일본어·영문 — 타겟이 외국인이므로 필수)
- [ ] 새로고침·뒤로가기 눌러도 안 깨지나
- [ ] 느린 네트워크에서 (F12 → Network → Throttling → Slow 3G)

발견한 건 **한 번에 모아서** 이슈로. 단 P0는 즉시.

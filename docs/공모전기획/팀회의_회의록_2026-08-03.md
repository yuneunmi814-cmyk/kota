> **일시** · 2026-08-03(일) 화상
> **참석자** · 전도준(CMO) · 최용우(COO) · 윤은미(CTO)
> **성격** · 07-29 오프사이트에서 합의한 *"각자 포지션 관점 MD 파일 작성 → 폴더 통합"* 의 중간 점검. 진도 정체를 확인하고 운영 체계를 재정비한 회의
> **한 줄 요약** · 각자 포지션 MD 파일을 **내일(8/4) 10:30까지 완성**해 통합하고, 미팅을 **주 3회**로 올리며, **git push는 CTO 전담·회의록은 COO 담당**으로 역할을 정리함.

## 1. 데이터 커버리지 문제 (CTO 실사용 발견)

- CTO가 주말에 **영월·제천 지역 축제에 직접 방문** → 코타에서 해당 축제 정보를 찾을 수 없었음.
- 현장에는 현수막 등 홍보물이 있으나 **우리 서비스에는 데이터가 없는 상태**.
- 조치 — 관광공사 오픈 API에 더해 **전국 지역축제 공공데이터를 추가 연동**.
- 추가 후에도 **영월은 반영되었으나 제천은 미반영**. 다른 지역축제 API 소스를 추가 조사하던 중 중단(토큰 한도).

> **[CTO 확인 사항]** 8/3 커밋 `9c343d8`으로 2개 소스 통합(**121건 → 416건**) 완료. 다만 도시 단위 밀도는 여전히 낮음(제천 1건·영월 1건·공주 2건). 제천 미반영의 원인은 **원본 공공데이터에 2026년판이 아직 등록되지 않은 것**으로 확인됨.

## 2. 검색 기능 부재 (COO 제기)

- COO: 현재 코타는 **전국 탭 / 지역별 탭**의 축제만 볼 수 있음. **"내가 가려는 지역"의 축제를 찾을 방법이 없음** → **검색 탭이 필요**하다.
- CTO: 현재는 내 위치 기반으로 정해진 지역만 노출되는 구조임을 확인.

## 3. 지역 분류 체계 문제 (CTO 제기)

- 경주·여수·강릉 등이 **시·도 단위가 아니라 시·군 단위로 쪼개져** 있어 분류가 일관되지 않음.
- CTO가 수정하기로 함.

## 4. 업무 분담·자료 관리

- COO가 **구글 시트로 할 일 관리표**를 만들어 카톡에 공유. 담당·상태·우선순위 컬럼 구성.
- **회의록 정리를 CTO → COO로 이관.** CTO는 녹음 원본만 전달하고 **개발에 집중**.
- 버그 리포트는 **CTO 레포의 GitHub Issue**로 제보(레포가 퍼블릭이므로 접근 가능 여부는 COO가 확인).
- 자료 배치 — **단타성 데이터(데일리 리포트·할 일)는 구글 시트**, **MD 파일·회의록 전문 등 누적 자료는 GitHub**.
  - CMO: *"기타(GitHub)는 AI 학습용·코드 저장용. 데일리/버그 리포트처럼 단타적인 건 push/pull이 과도해져 시트가 낫다."*
  - 노션은 탈락.

## 5. C-level MD 파일 작성 방법 (CMO 공유)

- CMO가 자신의 방식을 공유 — ① 초기 얼라인 내용 + 시장조사 스프레드시트 ② 타겟·고객·홍보 자료 ③ GitHub 누적 자료를 **통째로 넣고**, *"우리 조직은 CTO·COO·CMO가 있고 나는 CMO다"* 라는 맥락을 준 뒤 **MD 파일 기획부터 시키는** 방식.
- 각 파일마다 **"이 문서의 정의"** 를 두어 문서 간 역할을 구분.
- 포지션별로 필요한 정보가 다름 — 예: CTO는 어떤 기술을 쓸지·데이터를 어디서 가져올지·알고리즘·**새 API를 쓸지** 등.
- CTO 언급: **향후 우리 API를 판매할 수 있도록 설계해야 한다**는 조언을 받았음.
- **COO는 개념이 포괄적**이라 그대로 두면 인사·경영지원·CEO 전략까지 확장됨 → *"우리는 3인 스타트업"* 이라는 전제를 계속 부여해 **범위를 좁혀야(가두리) 함**.

## 6. 진도 정체 진단

- CMO: *"미팅이 일주일에 한 번은 너무 루즈하다. 이틀~3일에 한 번, 적어도 주 3회는 해야 진도가 나간다."*
- CMO: *"처음에는 열심히 했는데 허들이 높아지니까 기피하게 됐다."*
- CTO: *"COO 신혼여행 가기 전까지가 우리가 열심히 한 것 같다."* → CMO: *"맞다, 다 같이 풀어졌다."*
- 8월에 접어들었고 마감이 다가오므로 **진도를 빼야 한다**는 데 전원 동의.

## 7. 공유 사항 — 카카오 MCP 본선 진출

- CTO·COO가 참여한 **카카오 MCP 공모전 본선 진출**(약 300팀 중 20팀, 이 중 10팀 수상).
- 8/4 온라인 설명회 예정. **8월 중 개발 → 9월 초 마감** 예정.
- 코타 일정과 겹치므로 **리소스 배분 논의 필요**.

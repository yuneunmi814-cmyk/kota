# 팀 회의록 — AI로 굴러가는 조직·자동화·C-level 역할 분담

> **일시** · 2026-07-29(수) (용훈 님 별장 오프사이트, 화상 + 화면공유)
> **참석자** · 전도준(리드·CMO) · 최용우(COO) · 윤은미(CTO, 작성) 외 1명
> **성격** · 공모전 웹앱을 넘어, 팀 운영 자체를 **AI로 자동화하는 조직 구조**로 확장하는 방향 회의
> **한 줄 요약** · 제품/마케팅을 **자동화**로 끌고 가는 것이 핵심. 팀을 **CTO(윤은미)·COO(최용우)·CMO(전도준)** 로 재편하고, 각자 **본인 포지션 관점의 MD 파일**을 만들어 다음 회의 때 폴더로 통합하기로 함. COO가 **자동화 워크플로우 시제품**을 준비.

---

## 1. 핵심 방향 — "AI로 굴러가는 조직"
- 아이디어에 그치지 않고 **실제 성과가 나는 지점까지** 끌고 가야 유의미하며, 그러려면 **자동화**가 필수.
- **마케팅 엔진(바이럴)** 구축이 핵심 축. 초기에는 테스트: **키워드 선정 → 타겟 정의 → 채널·주기·콘텐츠 형태 결정 → 콘텐츠별 기능 개발**.
- 전도준: 컴퓨터 4대를 각각 C-level(COO/CMO/CEO/CTO)로 세팅해 테스트 중. 현재 **CMO 머신으로 테스트 진행 중** — "시키면 되더라".

## 2. 작업 방식 — MD 파일 → 교차 검토 → 기능 개발
1. **전체 그림을 먼저 제시**: "우리는 이런 회사를 만든다 / 조직엔 CTO·COO·CMO가 있다 / 나는 그중 OO 포지션이다".
2. Claude Code에 위 맥락을 주면 → **포지션에 맞춰 세분화된 MD 파일**을 생성(포괄적이 아니라 본인 역할 기준).
3. 각자 MD 파일을 **합쳐** → **클로드/GPT 교차 검토** → 최종 픽스.
4. 픽스본을 기준으로 **기능 개발**.

> 팁(전도준): 구두 프롬프트로 조직 구조·본인 포지션·개발할 프로그램을 설명하고 "MD 파일 만들어줘"라고 요청하면 됨.

## 3. COO의 전략적 중요성
- 상장·엑시트(매각/M&A) 시 **COO 역할이 핵심**.
- 대부분 기업이 테스트·의사결정 **히스토리와 회계 장부를 기록으로 남기지 않음** → 투자·인수 심사에서 불리.
- **히스토리 추적이 명확하고 회계가 투명**해야 투자·매각이 쉬움 → 이를 AI로 자동화하면 조직 넘기기(엑시트)도 수월.

## 4. 역할 분담 (결정)
| 포지션 | 담당 | 사유 |
|---|---|---|
| **CTO** | 윤은미 | 그동안 계속 개발을 해왔으므로 |
| **COO** | 최용우 | 자동화 구현 가능, 결국 남는 핵심 역할 |
| **CMO** | 전도준 | 마케팅이 적성 |

> 기존 개발 RNR(개발·배포=윤은미 / 디버깅=최용우 / PM·디자인=전도준)을 유지하면서, 그 위에 조직 운영 관점의 C-level 레이어를 얹는 개념.

## 5. 자동화·데이터 축적
- **[COO/최용우]** 다음 회의까지 **자동화 워크플로우 시제품** 구성. 구현 옵션: n8n / 워크플로우 자동화 / API 연동.
- **데이터 축적 도구** 선정 필요 — 후보: **구글 시트**(무난·생태계) / **옵시디언**(연동·검색) / 구글 드라이브 / **디스코드 봇 연동**.
- 원칙: **무료 버전 중 데이터가 가장 많이 쌓이는 것**, **조별·조직 형태별·날짜(일자)별** 정리. 회의록·아이디어를 바로바로 검색 가능하게.

# 회의 안건 — 기한 지남 3건 (8/14 회의용)

> 시트 기준 2026-08-13 · 작성 CTO
> **3건 모두 CMO(전도준) 담당**이며, 기한은 전부 **8/10**로 사흘 경과. 상태는 셋 다 `2-진행`.

---

## 한눈에

| # | 항목 | 상태 | 1차 제출(9/21) 필수? | CTO 제안 |
|---|---|---|---|---|
| CMO_3 | CEO 마스터 문서 최종본 | 2-진행 | **아니오** (내부 기준 문서) | 기한 8/22로 재설정 — 1차본은 레포에 있음 |
| CMO_4 | CMO 문서 누락분 보완 | 2-진행 | **아니오** (내부 문서) | 기한 8/22 · **범위 축소** 제안 |
| CMO_6 | 콘텐츠 OS 엔진 실행 | 2-진행 | **아니오** (홍보 자동화 도구) | 제출 이후(9/22~)로 이동 |

> **핵심**: 3건 다 제출물이 아니다. 반면 도준님 몫 중 **제출에 직접 영향을 주는 디자인 과제(CMO_5)는 기한이 비어 있다.** 우선순위가 뒤집혀 있는 상태 — 이 회의에서 바로잡는 게 목적.

---

## 1. CMO_3 — CEO 마스터 문서 최종본

- **현재**: 1차본 작성 완료(8/4). 레포에 반영돼 있음 → `docs/C-level/03_CEO/01_CEO_MASTER.md`
- **막힌 지점(추정)**: "임의 수정 금지, 수정 시 전체 얼라인" 조건 때문에 최종화에 3인 합의가 필요
- **제출 영향**: 없음. 단 **기능설명서의 '서비스 소개·주제 선정 이유' 작성 시 인용 근거**로 쓰이면 유용
- **제안**: 이번 회의에서 **10분 안에 얼라인**하고 그 자리에서 확정 처리 → 기한 넘길 이유가 사라짐. 안 되면 8/22로 재설정

## 2. CMO_4 — CMO 문서 누락분 보완

- **현재**: "비어 있는 항목이 많아 자료조사 기반으로 채우는 중"
- **제출 영향**: 없음(내부 문서 10종). 다만 **04_POSITIONING·06_SEO_GEO_STRATEGY**는 제출 서술에 재사용 가치 큼
- **제안**: **전량 완성 대신 2개만 우선 완성** — 포지셔닝, SEO/GEO 전략. 나머지는 제출 후로.
  - 근거: 8/12 사용자 인터뷰로 SEO/GEO 실행이 이미 구현 단계까지 갔으므로(테마 랜딩·프리렌더), 문서가 구현을 따라오기만 하면 됨

## 3. CMO_6 — 콘텐츠 OS 엔진 실행

- **현재**: "개인 프로젝트 기준으로 고정된 엔진 구조를 범용 메타데이터 형태로 수정 중"
- **제출 영향**: 없음. 홍보 콘텐츠 생산 자동화 도구
- **판단**: 제출 전까지 **홍보 활동 자체가 우선순위가 아님**(심사는 서비스·문서로 평가). 도구를 만드는 데 시간을 쓰면 정작 필요한 디자인이 밀린다
- **제안**: **제출 이후(9/22~)로 이동**. 지금은 코타 적용 테스트만 가볍게

| CMO_1 마케팅 엔진 설계 | 2-진행, 기한 없음 | 제출 후 홍보 단계에서 사용 |

### 2-1. 다국어 100% — 무엇을 했나

"상위 50~100개만 번역하자"던 권고안을 **전량 번역**으로 올렸습니다. 이유는 두 가지입니다.

1. **미번역이 계속 쌓이는 구조였다.** 주간 자동수집(5개 소스)에 **번역 단계가 아예 없어서**, 새 축제가 들어올 때마다 한국어로만 남았습니다. 이게 604건이 쌓인 근본 원인입니다.
2. **타겟이 일본·태국인데 축제명이 한국어면 못 읽는다.** 지역탭·UI만 번역해선 의미가 없습니다.

그래서 손번역 대신 **번역 엔진**을 만들었습니다 — 지명 사전(행정구역 188 + 산·강·명소 43) · 축제 어휘 사전(323개, 미번역 604건의 실제 어휘 빈도를 세어 선정) · 한글 음역기(로마자 표기법 + 가타카나 + 태국문자). 사전에 있으면 뜻을, 없으면 소리를 옮깁니다.

|---|---|
| 커버리지 | **718 / 718건 (100%)** × 3개 언어 |
| 품질 검수 | 사전이 못 덮은 항목을 뽑아 사전 보강 → 재생성을 4회 반복, 검수 대상 **137 → 81 → 37 → 0건** |
| 마지막 37건 | 허준·연오랑세오녀·건맥·미리내처럼 사전화가 부적절한 인물·설화·조어 → **직접 번역** |
| 지속성 | 주간 워크플로에 편입 — **다음 주 새 축제부터 자동 번역** |
